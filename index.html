Options & Backup

Automatically saves your classes, students, tables, rules, and seats in this browser. Avoid repeating previous seats makes Shuffle prefer different seats; it is not a strict rule. Export Backup downloads a JSON copy. Import Backup restores a saved copy and replaces the current data. Keep backups private because they contain student names. Local storage may not carry over between file versions or browsers.
